# python-fundamentals

> My Python learning journey in Jupyter notebooks — from first `print()` to classes, with small projects along the way.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue) ![Jupyter](https://img.shields.io/badge/Jupyter-notebooks-orange) ![License](https://img.shields.io/badge/License-MIT-lightgrey) ![Status](https://img.shields.io/badge/status-runs%20clean-success)

## About

A structured set of Jupyter notebooks I built while learning Python
fundamentals, organized as a path from the basics up to object-oriented
programming, plus a handful of small projects that put the concepts to work.
The numbered notebooks are meant to be read in order.

## Learning path

| # | Notebook | Topics |
|---|----------|--------|
| 01 | `01_python_basics.ipynb` | print, math, strings, variables |
| 02 | `02_more_basics.ipynb` | operators, type conversion, input |
| 03 | `03_collections.ipynb` | lists, tuples, sets, dictionaries |
| 04 | `04_conditionals.ipynb` | if / elif / else |
| 05 | `05_loops.ipynb` | for and while loops |
| 06 | `06_functions.ipynb` | defining and calling functions |
| 07 | `07_comprehensions.ipynb` | list/dict comprehensions |
| 08 | `08_comprehensions_and_lambdas.ipynb` | comprehensions + lambda expressions |
| 09 | `09_exception_handling.ipynb` | try / except / finally |
| 10 | `10_file_handling.ipynb` | reading and writing files |
| 11 | `11_intro_to_oop.ipynb` | classes, objects, methods |

## Projects

Small programs that apply the fundamentals (in `projects/`):

- `simple_calculator.ipynb` — four-function calculator
- `number_guessing_game.ipynb` — guess-the-number game
- `rock_paper_scissors.ipynb` — play against the computer
- `temperature_converter.ipynb` — Celsius / Fahrenheit conversion
- `number_base_converter.ipynb` — decimal to octal / hex / binary

## Exercises

Practice work in `exercises/` (problem-solving drills and a host-info assignment).

## Getting started

```bash
pip install -r requirements.txt
jupyter notebook       # then open any notebook
```

The numbered notebooks run cleanly top-to-bottom. The projects and some
exercises use `input()`, so run those cell-by-cell and type your answers.

## Skills demonstrated

- Core Python: data types, control flow, functions, comprehensions, OOP
- File I/O and exception handling
- Turning concepts into small working programs
